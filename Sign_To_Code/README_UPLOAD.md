Sign-to-Code Pitch PPTX

Files produced:
- `Sign_to_Code_Pitch.pptx` — 7-slide pitch deck for hackathon initial submission

How to run locally (Windows PowerShell):

1) Create and activate a venv, then install python-pptx:

```powershell
python -m venv .venv; .\.venv\Scripts\Activate.ps1; pip install python-pptx
```

2) Run the generator script (creates the PPTX in this folder):

```powershell
python generate_ppt.py
```

Upload instructions for Google Drive (public link):
1) Open https://drive.google.com and sign in.
2) Click New → File upload, select `Sign_to_Code_Pitch.pptx`.
3) Once uploaded, right-click the file → Get link.
4) Change link access to "Anyone with the link" and copy the URL.
5) Paste the URL in your hackathon submission form.
